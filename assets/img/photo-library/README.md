## Integration notes

- No existing images or page references have been replaced.
- Use descriptive alt text only when the image conveys information. Use `alt=""` for a decorative hero that repeats adjacent content.
- Preserve explicit width and height. Lazy-load below-the-fold imagery; do not lazy-load the main hero.
- Crop suggestions are starting points, not tested placements. Check faces and probe contact at 390 px and 1440 px before shipping.
- The hero has text-safe space on the left in the source image. The current desktop hero renders its image only in the right 64% of the viewport. Reconsider that geometry or crop carefully rather than blindly replacing the source.
- Do not replace the existing scientific ultrasound image with an AI-generated scan. The probe detail is a supporting illustration only.
- Do not change article titles, dates or marketing copy without approval. New photo placement does not authorize new claims.
